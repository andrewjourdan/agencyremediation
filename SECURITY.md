# Security policy

This policy covers the current Agency Remediation site at `agencyremediation.com` and the code that serves it from this repository.

## Report a vulnerability

Email [steward@agencyremediation.com](mailto:steward@agencyremediation.com?subject=Agency%20Remediation%20security%20report) with the affected URL or file, steps to reproduce, and the potential impact. Redact credentials and personal data from any evidence.

Please report suspected vulnerabilities privately and give the maintainer time to investigate before publishing details. Use GitHub issues for ordinary bugs and content corrections.
