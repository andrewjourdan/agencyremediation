# Contributing

Open a pull request against `main` with a brief description of the change and how you checked it. Keep portfolio claims aligned with the status shown on the relevant property site.

Before requesting review, preview the site locally and check the affected content at desktop and mobile widths. Test any links and interactive controls you touched. For request-form changes, confirm the draft contains the expected details in your mail app.

After a deployment, check the affected pages on [agencyremediation.com](https://agencyremediation.com/). Report security issues privately as described in [SECURITY.md](SECURITY.md).
